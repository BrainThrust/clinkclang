# Clinkclang

Snap together smart web agents in one shot.

ClinkClang is a reusable library with everything you need—components, orchestration, LLMs, memory, tools, and structured outputs—to build web app agents fast.

## Getting Started

Dependencies:

- pnpm
- node
- npm
- zod
- shadcn/ui (For components)

## Installation

```bash
pnpm dlx clinkclang@latest init
```

## Adding Components

```bash
pnpm dlx clinkclang@latest add agent-core
```

Read the [docs](https://clinkclang.com) for more information.
