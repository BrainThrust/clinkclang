# Clinkclang

The Point of this project is to create simple components in a shadcn style to copy and paste into other projects.

## Getting Started

Dependencies:

- pnpm
- node
- npm
- zod
- shadcn/ui (For components)

## Installation

```bash
pnpm dlx clinkclang@latest init
```

## Adding Components

```bash
pnpm dlx clinkclang@latest add agent-core
```

Read the [docs](https://clinkclang.com) for more information.
